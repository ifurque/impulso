# Funcionalidades principales

## 1. Registro e ingreso

El sistema permite que un usuario cree una cuenta o inicie sesión para:

- crear negocios
- administrar su emprendimiento
- gestionar pedidos, turnos y publicaciones

## 2. Creación de emprendimientos

Cada usuario puede crear un negocio con:

- nombre, categoría, descripción y ubicación
- datos de contacto
- foto de perfil y portada
- configuración de turnos y delivery
- configuración de medios de pago

## 3. Panel del emprendimiento

Desde el panel se gestiona:

- stock de productos
- ingresos y gastos
- turnos
- pedidos
- consultas
- miembros del equipo
- disponibilidad horaria
- publicaciones y redes sociales

## 4. Productos y catálogo

Es posible registrar productos con información como:

- nombre
- categoría
- marca
- modelo
- unidad
- cantidad
- precio
- número de catálogo

También se soporta ingreso de stock y gestión de inventario.

## 5. Turnos y agenda

El sistema soporta reservas para servicios o atención presencial. Incluye:

- disponibilidad semanal por día
- horarios configurables
- validación de slots libres
- confirmación por correo
- reprogramación y cancelación por token

## 6. Delivery y pedidos

Los negocios pueden ofrecer entrega o retiro. El sistema permite:

- registrar pedidos de clientes
- gestionar método de entrega
- gestionar estado del pedido
- controlar coordinación geográfica (latitud/longitud)

## 7. Consultas y mensajes

Los clientes pueden enviar consultas desde un negocio. El dueño puede:

- verlas en la bandeja
- responderlas
- cambiar su estado
- cerrar consultas resueltas

## 8. Publicaciones del negocio

El emprendimiento puede publicar contenido en la zona pública:

- publicaciones visibles
- fecha de inicio y fin
- contenido asociado al negocio
- enlaces a redes sociales

## 9. Personalización pública

La parte pública de cada negocio puede adaptarse visualmente con:

- paleta de colores
- fondo
- tipografía
- forma de tarjetas y botones
- estilo de imagen de perfil
- patrón y textura visual

## 10. Reseñas

Los clientes pueden dejar reseñas visibles para reforzar la confianza del negocio.

## 11. Explorar negocio

La plataforma pública permite navegación y búsqueda desde la vista general del sitio, donde cada empresa puede mostrar su identidad y sus servicios.

## 12. Seguridad y permisos

Se restringe el acceso a:

- panel de negocio
- creación de emprendimientos
- administración de miembros
- gestión de estados y datos sensibles

Convalidaciones y middleware para que solo el propietario o personal autorizado pueda gestionar cada negocio.
